Put your X-Station / KS (.syx) patch banks in this folder.

Jamiro loads every program it finds here when it starts:
the first file (in alphabetical order) becomes programs 100-199, the second 200-299, and so on.

No sound banks are included with Jamiro. Use banks you own, for example the ones Novation
published for the X-Station. This folder is kept when the plugin is updated.
